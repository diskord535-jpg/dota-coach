# Dota Coach

Помощник-тренер для Dota 2 под Windows: подсказки поверх игры — таймеры (стаки, руны, Рошан, нейтралки), помощь в
пике, сборка под ваших врагов, разбор смертей, вкладка «Тренер» с объяснениями.

**Программа ничего не делает за вас**: не читает память игры, не нажимает клавиши и не показывает того, чего вы не
видите сами. Данные берутся только из официального Game State Integration от Valve.

## Скачать

👉 **[Последняя версия — страница загрузки](../../releases/latest)** → файл `DotaCoach_…_x64-setup.exe`.

1. Запустите установщик (права администратора не нужны). Если Windows покажет «Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае» (программа не подписана платным сертификатом).
2. При первом запуске мастер настройки сам подключит Dota 2 и подскажет, что включить в Steam и в игре.

## Обновления

Программа сама проверяет новые версии и предлагает «Установить» — ничего скачивать вручную не нужно.
Каждое обновление подписано ключом автора, и программа ставит только подлинные файлы.
